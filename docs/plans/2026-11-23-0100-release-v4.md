## 要改的文件 / 要做的事

1. `.gitattributes`：末尾加一行 `/docs/plans export-ignore`。
2. `composer check` 通过后，在本计划写「结果」的前半（做到这一步的情况），`git add -A`、`git commit`（多个 -m）。
3. `git checkout main`，`git merge --ff-only v4-simplify`。
4. `git push origin main`。
5. `git tag -a v4.0.0 -m "v4.0.0: Standard Laravel backend, four steps and two hooks"`，`git push origin v4.0.0`。
6. `gh release create v4.0.0 --title "v4.0.0" --notes-file <草稿>`。说明草稿放在会话的临时目录（不进仓库），内容：
   - **Removed**: the parts (operations, listings, records, files, webhooks, outside calls, background jobs), the workflow tool and its rules, the browser tests and the /style demo, TypeScript type generation.
   - **Now**: the official Laravel React Starter Kit with a standard Laravel backend (controllers → Actions → Policies, FormRequests), `AGENTS.md` with four steps for every task (grill, plan, 开始, result), two hooks (plan gate, check before stopping), Laravel Boost guidelines and skills, architecture rules in `tests/Unit/ArchTest.php`.
   - **Upgrading from v3**: there is no automatic upgrade; start a new project with `laravel new my-project --using=ryanc342/laravel-agent-starter` and move your code over. Code that used the parts must be rewritten as plain controllers and Actions.
7. 等 CI（`gh run watch` 或 `gh run list`）；等 Packagist 出现 v4.0.0（查 `https://repo.packagist.org/p2/ryanc342/laravel-agent-starter.json`）。
8. 在会话的临时目录里 `laravel new v4_release_probe --using=ryanc342/laravel-agent-starter`：确认 composer.lock / 安装输出是 v4.0.0、没有 `docs/plans/`、`composer check` 通过。然后删掉目录，`DROP DATABASE v4_release_probe` 和 `v4_release_probe_test`（只删这两个自己建的）。
9. 在本计划写完「结果」，在 main 上 `git add -A`、`git commit`、`git push origin main`，留在 main。
