### 要你决定的事

- 类型错误的那次验证，实际是被 lint 拦下的。要看 tsc 单独能不能拦，得写一个 lint 抓不到的类型错误（比如给一个已经用到的变量写错类型）再试一次。需要的话开一份新计划。
- 现在没有批准的计划时，`cd x && git status` 这种写法也会被拦，AI 要直接写 `git status`。这是预期的行为，只是提醒一下。
