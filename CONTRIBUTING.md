# Contributing

English and Chinese issues and pull requests are welcome.

- Bugs: open an [issue](https://github.com/Ryanc342/laravel-agent-starter/issues) with steps, expected and actual behaviour, and your PHP, Node.js and MySQL versions. Security problems go through [SECURITY.md](SECURITY.md).
- Changes: discuss the scope in an issue first, then follow the four steps in [AGENTS.md](AGENTS.md); a pull request links its plan in `docs/plans/`.
- Before opening a pull request, run `composer check` with MySQL running. Do not skip tests, silence checks or change existing assertions unless the plan says so.
- Contributions are under the [MIT license](LICENSE).
