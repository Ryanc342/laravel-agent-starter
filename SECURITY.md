# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/Ryanc342/laravel-agent-starter/security/advisories/new). On the repository's Security tab, choose **Report a vulnerability**.

Include the affected commit or version, reproduction steps or a minimal proof of concept, expected impact, and relevant environment details. Do not include live credentials or unrelated private data. Avoid public issues and pull requests that disclose an unpatched vulnerability.

The maintainer will review reports as availability permits; this project does not promise a response deadline or a bug bounty. Coordinated disclosure can be discussed in the private report.

## Supported code

Security fixes target the current `main` branch. Older snapshots and applications created from this template do not receive changes automatically: their maintainers must review and apply relevant updates and keep their own dependencies current.

For vulnerabilities in an upstream dependency, use that project's reporting policy. If the template's configuration or integration is also affected, report that impact here privately.
