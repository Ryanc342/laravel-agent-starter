# TYPES: Frontend types

Location: `resources/js/types/`

This card applies to every file in its location. Every rule here applies in full; the tag says who guarantees it.

## Does

- **TYPES-1** The data shapes the frontend uses: the types of Resources are generated in generated.d.ts; which data a page receives, the shared data and the paginated wrapper are written by hand. `note`
